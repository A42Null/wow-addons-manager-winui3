## 2026-11-10 修复「部分版本下没有找到匹配的插件」

根因（两个源不同，均已修）：
1. **新手盒子 wclbox**：非默认版本的 JSON-LD 条目 URL 带 `?version=N` 后缀
   （如 `.../PluginItem/15714?version=2`），原正则要求 URL 以 `/PluginItem/{id}"` 结尾 → 只有默认版本 4（泰坦）能解析，
   其余版本（正式服2/经典旧世6/无限9…）全部 0 条。修复：正则允许 `(?:\?[^"]*)?` 尾缀。
2. **大脚插件站 178**：站点改版，列表 HTML 由 `span.num/tit/dig/size` 改为
   `h2.h2 > a[href=/ui/{id}]` + `span.pic/down/date` + `div.dig` → 旧正则 0 匹配（任何筛选都空）。
   修复：按 `<div class="item">` 块切分解析；列表分类由 `0_34676` 改为 `0_37499`（全部插件）。
3. 浏览页并发竞态：切换源时 `ApplySourceVisibility` 会连发多次搜索，旧结果后到会覆盖新结果。
   修复：`_searchSeq` 只渲染最新请求；`_suppressVersionEvent` 抑制初始化事件。
4. 源侧请求失败不再静默返回空列表（会误报"没有找到匹配"），改为抛错显示"搜索失败"；
   版本筛选无命中时自动回退全部版本并在 InfoBar 提示。

其他：wclbox 关键词搜索扫描深度 8 页→20 页（600 条）；178 新增版本筛选（按名称前缀 + main_game_version 判定，
1.13=TBC/1.14=经典旧世/1.15=永久60/2.x=熊猫人/3.4=TBC/3.8=泰坦/10+=正式服，多值或无法识别→宽松保留）。

按用户要求暂停：MSI 安装包编译（CI 改为需仓库变量 ENABLE_MSI=true 才生成）、CNB Release 创建与资产上传（.cnb.yml 已移除该阶段）。
