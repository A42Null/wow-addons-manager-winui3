- 从零搭建 WinUI3 应用：NavigationView 三页（已安装/浏览 CurseForge/设置），服务层 ConfigService(JSON 配置至 %LOCALAPPDATA%)、CurseForgeService、WowInstallService。
- 客户端版本识别（用户确认）：`_retail_`=正式服(11.x/12.x)、`_classic_`=熊猫人之谜怀旧服(5.x)、`_classic_titan_`=泰坦重铸时光服(WLK **3.80.x** 国服，注意是 3.80 不是 3.8)、`_anniversary_`=周年 TBC(2.x)、`_classic_era_`=永久60(1.14/1.15)。Forever 版未出。

- 用户要求：**不要本地编译**，用 GitHub Actions + CNB 云构建。
- 本机 `dotnet build` 与 CI 上 dotnet CLI 都触发 XamlCompiler.exe exit 1（无 output.json），换 VS MSBuild（microsoft/setup-msbuild）后能报出真实错误。
- 修复过程：① InfoBadge 无 `IsDot` 成员 → 用 `AttentionDotInfoBadgeStyle`；② 缺 `using WoWAddonManager.Models`；③ RowViewModels 缺 `using Microsoft.UI.Xaml.Media.Imaging`；④ release job 里 `gh release create` 需要 `--repo` 参数（无 checkout 时无 git 上下文）。

- 仓库：GitHub `A42Null/wow-addons-manager-winui3`（公开），Release **v0.1.0** 已发布（WoWAddonManager-win-x64.zip 62.77MB，自包含免安装）。
